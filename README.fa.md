## نصب

### ویندوز

1. فایل نصب را باز کنید: روی کامپیوترهای ARM (مثل لپ‌تاپ‌های اسنپدراگون) **فایل نصب ARM** و روی بقیه‌ی کامپیوترها **فایل نصب**.
2. اگر پیام Windows SmartScreen ظاهر شد، روی **More info** و بعد **Run anyway** بزنید.
3. درخواست دسترسی مدیر (Administrator) را تأیید کنید. RayLink یک سرویس کوچک نصب می‌کند که اتصال را برقرار می‌کند.

برای به‌روزرسانی، نسخه‌ی جدید را روی نسخه‌ی قبلی نصب کنید؛ سرورها و تنظیمات شما حفظ می‌شوند. برای حذف RayLink، از **Settings → Apps** آن را Uninstall کنید.

### مک

1. فایل DMG را باز کنید و **RayLink** را به پوشه‌ی **Applications** بکشید.
2. RayLink را باز کنید. بار اول، برای نصب سرویسی که اتصال را برقرار می‌کند، رمز عبور مک را می‌پرسد.
3. برای اسکن کد QR روی صفحه، وقتی پرسیده شد، در **System Settings → Privacy & Security → Screen Recording** به RayLink اجازه بدهید.

ممکن است بار اول macOS جلوی باز شدن RayLink را بگیرد. در این صورت به **System Settings → Privacy & Security** بروید و **Open Anyway** را بزنید.

### اندروید

1. فایل APK را روی گوشی باز کنید.
2. اگر اندروید پرسید، به مرورگر یا برنامه‌ی مدیریت فایل اجازه‌ی نصب برنامه بدهید، بعد **Install** را بزنید.
3. اولین باری که وصل می‌شوید، به RayLink اجازه‌ی ساختن اتصال VPN بدهید.

نسخه‌های جدید روی نسخه‌ی قبلی نصب می‌شوند و سرورهای شما سر جایشان می‌مانند.

### لینوکس

**Ubuntu، Debian، Linux Mint**

<div dir="ltr">

```bash
sudo apt install ./raylink_1.0.1-47_amd64.deb
```

</div>

**Fedora، RHEL**

<div dir="ltr">

```bash
sudo dnf install ./raylink-1.0.1-47.x86_64.rpm
```

</div>

**سایر توزیع‌ها**

<div dir="ltr">

```bash
chmod +x RayLink-1.0.1-47-x86_64.AppImage
./RayLink-1.0.1-47-x86_64.AppImage
```

</div>

AppImage اولین باری که اجرا می‌شود، برای نصب سرویس اتصال، رمز عبور شما را می‌پرسد.

در GNOME، آیکون RayLink در نوار وضعیت به افزونه‌ی *AppIndicator and KStatusNotifierItem Support* نیاز دارد که Ubuntu آن را از قبل دارد.

برای حذف RayLink، دستور `sudo apt remove raylink` یا `sudo dnf remove raylink` را اجرا کنید.
